# Instructions and Notes

** Push changes to Remote
1. Git Commands
- `git branch -M main`
- `git remote add origin <remote URL>`
- `git remote -v`
- `git push -u origin main`
2. Issues
- `git config --list`
- `git push -f origin main` --> force push
3. Remember this - `ACP` - `Add commit push`
